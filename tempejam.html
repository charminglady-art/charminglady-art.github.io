The Challenge

Tempe Jam has always been a celebration of local music, but the branding had drifted toward "family festival" instead of "indie music scene." My challenge was to create something that felt fresh, sophisticated and a little weird without losing the community spirit that made the event special.

Updating a Loved Brand

The previous Tempe Jam branding was already onto something: Tempe's city logo is the sun, the neighborhood buses are named after planets and it all made sense to me that everyone in Tempe was just an astronaut jamming out in space.

The old artwork used stock astronaut illustrations with instruments drawn on top. I wanted to keep the idea but scrap the graphic novel look, so I brought in an illustrator to create astronauts with realistic shadows and dynamic poses.

The visual language pulled inspiration from NASA's 1964 graphics standards and Brutalist design, combining bold typography, heavy contrast and clean structure.

These are the stickers we gave away at the Jam. The astronauts were illustrated by Kelsey Phillips. I provided a style guide and art direction. Since sound doesn't travel through space, we decided that the astronauts should only be playing electric instruments and are sending signals to their friends through space.

(function () { document.querySelectorAll('.image-scroller').forEach(function (wrap) { var track = wrap.querySelector('.image-scroller-track'); if (!track) return; track.innerHTML += track.innerHTML; // duplicate once for a seamless loop var toggle = wrap.querySelector('.image-scroller-toggle'); var icon = toggle ? toggle.querySelector('.toggle-icon') : null; var position = 0; var speed = 0.5; // pixels per frame var prefersReducedMotion = window.matchMedia('(prefers-reduced-motion: reduce)').matches; var paused = prefersReducedMotion; function setUI(isPaused) { if (!toggle) return; toggle.setAttribute('aria-pressed', String(isPaused)); toggle.setAttribute('aria-label', isPaused ? 'Resume scrolling' : 'Pause scrolling'); if (icon) icon.innerHTML = isPaused ? '▶' : '❙❙'; } setUI(paused); function step() { if (!paused) { position -= speed; if (position <= -(track.scrollWidth / 2)) position = 0; track.style.transform = 'translateX(' + position + 'px)'; } requestAnimationFrame(step); } if (toggle) { toggle.addEventListener('click', function () { paused = !paused; setUI(paused); }); } requestAnimationFrame(step); }); })();
